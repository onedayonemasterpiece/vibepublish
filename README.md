# vibepublish

Standalone project scaffold for a requirement-led publishing system.

The repository is intentionally light on application code for now. It already includes:

- strict agent and requirements governance in `AGENTS.md`;
- feature-oriented documentation layout in `docs/`;
- a ready-to-connect Google AI / Supabase limit-control framework in `google_ai/`;
- SQL migrations for the limiter in `migrations/`;
- VS Code workspace settings for opening this project separately.

Start with `docs/README.md` and `docs/routes.yml` before adding feature requirements.
