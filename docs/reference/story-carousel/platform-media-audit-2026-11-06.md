## 2. Alpha и действительный предел текущего media path

**Verified:** `social_operations/assets.py::verify_image` принимает PNG/JPEG/WebP, проверяет размер и изображение, применяет ориентацию и переносит его на белый RGB-фон. Alpha теряется в нормализованном результате. `insert_verified_image` сохраняет исходные байты отдельной приватной записью и нормализованную производную другой записью, а наружу возвращает ID производной. Следовательно, замечание Opus о потере прозрачности в обычном импортированном ресурсе справедливо.

**Важное уточнение:** «вырезанные изображения и прозрачные компоненты вообще невозможны» — слишком сильный вывод. Оригинал сохраняется; стандартный редактор/локальный проект может работать с прозрачными файлами до такого импорта. Но существование приватной оригинальной записи ещё не означает, что у dot уже есть разрешённый и проверенный способ получить её по опубликованному resource ID. Не надо угадывать ID или обходить границы доступа.

**Verified:** обычный preview ограничен 768px по длинной стороне. Однако `render_asset_full` уже существует: возвращает текущий asset без изменения при размере до 2MiB и длинной стороне до 2560px; иначе создаёт уменьшенную производную с `reencoded=true`. Поэтому утверждение «модели всегда доступно только 768px» неверно. Одновременно `full` означает полный **выбранный ресурс**, а не автоматическое извлечение исходного PNG с alpha. Если импорт вернул белую производную, full не восстановит прозрачность.

Источник: [assets.py](https://github.com/onedayonemasterpiece/vibepublish/blob/9e3ae5d07970ab0689904441a6496f9439bc1dcd/social_operations/assets.py), blob `ff6af906a81e6f65b5e101991c992f79cce81a84`.

**Предлагаемое минимальное следствие:** выбрать один явный, разрешённый путь передачи исходного компонента между автором проекта и dot, сохраняющий точные байты/alpha, и проверить его при реализации. Не создавать второй универсальный media framework. Раздельные виды — полотно, карточка, шов и локальный фрагмент — всё равно полезнее одного большого full для визуального анализа. Для полотна 7×1080px превью в 50% имеет ширину 3780px; его нельзя молча обещать как существующий generic full. Ссылка на отдельный render artifact или фрагменты решают другую задачу, чем общая максимальная величина preview.

## 3. Отказы генерации: факт, предположение и чрезмерные ограничения

**Verified, код:** действующий `adapters/codex_task_imagegen.py` запускает native imagegen через установленный skill, сохраняет состояние задания и выполняет read-only reconciliation. Это источник сведений о существующем исполнителе Vibe. Он не доказывает, что будущий dot использует тот же провайдер, модель, версию или ограничения. В проверенном коде не обнаружено таблицы запретов «любая советская символика / реальный человек / историческая война».

**Not checked:** реальные отказы dot по конкретным заданиям, актуальная провайдерская политика для каждого примера, качество генерации табличек и точных исторических эмблем. В этой проверке генерация не выполнялась.

Таблицу Opus с категорическим «не генерировать» для широких исторических категорий нельзя выдавать за установленный контракт. Плохая точность надписи, неподходящий crop, техническая ошибка задания и отказ по правилам — разные события. Возможность использовать оригинальное фото или обычный вектор для разрешённой задачи может быть хорошим творческим решением; она не должна описываться как способ обойти реальный отказ, скрыть контекст или перевести запрещённую цель в другой инструмент.

Минимальный журнал достаточен: операция/инструмент и известная версия; наблюдаемый код/краткая причина; исходная разрешённая цель; следующий допустимый художественный план. Не нужны скрытые рассуждения модели, словарь маскировочных формулировок или обязательная серия проб на десять отказов. Отдельное разрешение пользователя на каждый штатный творческий шаг также не нужно.

Источник: [codex_task_imagegen.py](https://github.com/onedayonemasterpiece/vibepublish/blob/9e3ae5d07970ab0689904441a6496f9439bc1dcd/adapters/codex_task_imagegen.py), blob `2174a7fb6d3419b502656b55f89ea660e6a406bc`.
