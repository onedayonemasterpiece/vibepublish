# Шаг 1 · Материал, исследование и история

Сделай:
1. Прочитай исходник целиком; сохрани точные слова, наблюдение и намерение автора отдельно от проверяемых утверждений. Повествуй от лица «Полюбить Калининград», не об авторе в третьем лице. Допустимы компактные подписи фотографа и нужного источника (10-storytelling §6).
2. Просмотри все исходные фото, выбери лучшие и обязательно включи сильнейший кадр героя; дополнительные интернет-фото — с источником. Сильный объект используй без фона на карточках/между ними, как в референсах; вырезка с живым фото узнаваемого места — рекомендация, критерий — красота и притягательность. Для истории об изменении исследуй исходный тред и архивы (например, PastVu): документальная пара «было/стало» нужна, когда раскрывает историю. Если подходящего кадра «до» нет, продолжай с подтверждёнными материалами, не выдумывая прошлое.
3. Исследуй нужные для рассказа детали; свяжи факты и точные цитаты с источниками, отдельно запиши гипотезы и границы сведений.
4. Напиши цельную авторскую историю с предметом, развитием и выводом. Тезисы и наблюдения автора — основа: каждый из них попадает в историю вместе со своим смыслом (почему это важно); чего нет — дорабатывай; затем выбери арку и число карточек по её содержанию.
5. Сохрани дословную первичку в `story.materials`, смысловые пункты с `material_ids` и модальностью в `points`, рассказ в `narrative`, раскадровку в `cards`. Длинный источник не сокращай: добавляй точные части с ID и `continuation_of`.

Артефакт — приватная история. Подставь свой материал и рассказ; уникальный ключ сохраняй для повтора:

```json
{"command":{"kind":"create","story":{"materials":[{"id":"m1","text":"Дословный исходник","source":"Ссылка на источник"}],"points":[{"id":"p1","text":"Смысловой пункт","material_ids":["m1"],"modality":"position"}],"narrative":"Цельный рассказ","cards":[{"id":"c1","text":"Заголовок\nОбъясняющий текст","point_ids":["p1"]}]}},"request_key":"unique-story-create"}
```

`points[]`: `{id,text,material_ids,modality}`; `cards[]`: `{id,text,point_ids}`. Все поля новой сущности обязательны. Modality по происхождению/статусу: `observation` — непосредственное наблюдение; `source` — сообщение источника; `hypothesis` — предположение; `position` — авторская позиция. Это не проверка достоверности. `fact`/`plan` нет: план из источника — `source`, предположение о будущем — `hypothesis`; в тексте сохраняй атрибуцию и статус плана. HOOK/CTX/… — редакционные роли, не поле `role`; поля `title` нет, заголовок и пояснение вместе в `text`.

Сохрани `carousel_id` и `revision`; `revise(story_changes:...)` меняет по ID с одним `expected_revision`. Новая версия материала — `material_add` с новым ID и `supersedes`; SVG-only сохраняет историю. Legacy: старый brief наследуется, явно переданный заменяется целиком; переход через `revise(story:...)` однократный, затем brief исторический и больше не записывается. Решения — в `note`, без самоотчёта.
