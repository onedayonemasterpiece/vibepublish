# Шаг 7 · Компоненты

Практически всё создавай генерацией по компонентам: сильные надписи, поясняющее повествование, объекты и фактуры. Проверяй точность текста, не удаляй мини-абзацы ради красивых заголовков. Если генерация сильно искажает изображение, используй исходник; документальные фото и исторические надписи на них не перерисовывай. Для каждого компонента:
1. Выбери способ встраивания F1–F8 по фону места; сильный объект без фона — генерация на вырезанном фоне его места (F1: фото автора — источник, тот же снимок с высокой точностью, меняется только фон на фон карточки; настоящее фото тоже покажи в истории); обрезка инструментом — запасной способ.
2. Посмотри уже сделанные компоненты той же роли (`get(scope:components)` / `render(region)`) и подай 1–2 генератору как образец.
3. Генерируй своим инструментом dot; для F1 получи `render(region, scale:1, layers:{only:[id слоёв]}, save_asset:true)` и приложи генератору именно изображение реального фрагмента, а не один URI.
4. Проверь компонент до импорта (края, артефакты, буквы, форма документа).
Возьми: 60-generation § «§0 Способы», нужный § «§2/§3/§4/§5», § «Контроль качества»; 85-style-continuity § «§2»; иконки — `get(scope:icons)`.
Артефакт: импортированные ассеты; note «s07: компонент …, способ F.., образец …».

Перед переходом: в note перечисли, что из этой карточки применено, и что сознательно пропущено (одной строкой).
