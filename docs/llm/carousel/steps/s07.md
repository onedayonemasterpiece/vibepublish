# Шаг 7 · Компоненты

Практически всё создавай генерацией по компонентам: сильные надписи, поясняющее повествование, объекты и фактуры. Проверяй точность текста, не удаляй мини-абзацы ради красивых заголовков. Если генерация сильно искажает изображение, используй исходник. Документальный кадр со средой сохраняй как свидетельство; сильный объект отдельно от фона создавай по F1/F2, точно сохраняя его видимые детали по исходному фото, включая надписи, без выдуманных дополнений. Для каждого компонента:
1. Выбери способ встраивания F1–F8 по фону места; сильный объект без фона делает генератор по целому фото автора, без предварительной обрезки инструментом — на цвете фона карточки (F2) или на куске её фона (F1); фото автора — источник, тот же снимок с высокой точностью, меняется только фон на фон карточки; из серии снимков один, не обязательно тот же, покажи с настоящим фоном для доверия; обрезка инструментом — запасной способ. Самый сильный снимок показывай целиком и крупно, без порчи кадрированием. Несколько объектов без фона — из разных снимков серии, не один снимок дважды.
2. Посмотри уже сделанные компоненты той же роли (`get(scope:components)` / `render(region)`) и подай 1–2 генератору как образец.
3. Генерируй своим инструментом dot; для F1 получи `render(region, scale:1, layers:{only:[id слоёв]}, save_asset:true)` и приложи генератору именно изображение реального фрагмента, а не один URI.
4. Проверь компонент до импорта (края, артефакты, буквы, форма документа).

Артефакт: импортированные ассеты; note «s07: компонент …, способ F.., образец …».
