# Шаг 7 · Компоненты

Для каждого компонента (объект-герой, леттеринг, фактура, иконка):
1. Выбери способ встраивания F1–F8 по фону места.
2. Посмотри уже сделанные компоненты той же роли (`get(scope:components)` / `render(region)`) и подай 1–2 генератору как образец.
3. Генерируй по шаблону; для F1 — `render(region, scale:1, only/hide, save_asset)` и генерация по этому фрагменту.
4. Проверь компонент до импорта (края, артефакты, буквы, форма документа).
