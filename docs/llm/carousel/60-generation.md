# 60 · Генерация компонентов

## §0 Способы встроить сгенерированный компонент в холст (выбери по фону)

Любой компонент — надпись, объект, иллюстрация — встраивается одним из способов. Способ выбирается по фону места и по тому, как компонент должен лечь. Способ записывай в `revise.note`.

| ID | Способ | Когда | Как |
|---|---|---|---|
| F1 | **Генерация по фрагменту фона** (основной для каскада) | фон уже собран: сгенерированная подложка, фото, сложная фактура | 1) собери холст без этого компонента (скетч-место пустое); 2) `render(view:"region", region:[x,y,w,h], scale:1, only:[id фоновых слоёв], save_asset:true)` — точный кусок фона 1:1; 3) подай этот кусок генератору как входное изображение: «впиши надпись «…» в эту область, [стиль, плотность, цвет], края, фон и освещение за пределами букв не менять, размер и пропорции сохранить»; 4) импортируй результат и поставь ровно в те же `x,y,w,h`; 5) при малейшем сдвиге тона по краю — маска с растушёвкой 24–48 px (70-montage §11) |
| F2 | **На однотонной зоне** | место — ровный цвет (панель, плашка, однотонный фон) | генерация на точном `#hex` зоны, без теней и текстуры; ставится без маски |
| F3 | **Под цвет и градиенты краёв** | фон — плавный градиент или спокойная фактура | в промпте цвет по каждому краю и направление градиента (§1); ставится без маски, стык проверить `render(region)` |
| F4 | **Вырезка с прозрачностью** | объект/надпись должны лечь поверх разных фонов, через шов, поверх фото | PNG с альфой (если инструмент даёт) или контур `clipPath` по силуэту; alpha в рендере сохраняется |
| F5 | **Страйпы по bbox строк** | многострочная надпись, строки расходятся ступенькой/через шов, сложный фон | леттеринг целиком → `clipPath` прямоугольниками строк (70-montage §4); каждую строку ставь отдельно |
| F6 | **Маска сложной формы** | иллюстрация/фото в органической форме, арка, капля, силуэт | `clipPath`/`mask` с `path` (70-montage §3) |
| F7 | **Перегенерация сегмента фона целиком с компонентом** | компонент — часть среды (памятник в пейзаже подложки) | генерируй сегмент подложки вместе с объектом (§1 + §2), по фрагменту соседних сегментов на входе для совпадения краёв |
| F8 | **Типографический набор шрифтом пакета** | точный текст, тело, числа, факты | `<text>` (40-typography), без генерации |

Правила выбора: точные факты, числа, тело — только F8. Заголовок-образ на сложном фоне — F1 (лучше всего сохраняет свет и фактуру) или F5. На однотонной панели — F2. Объект через шов поверх разных зон — F4. Одна история может использовать несколько способов, но для одинаковых ролей (все заголовки) — один.

## Общие правила генерации (для любого компонента)

Каждое задание генератору содержит: **назначение** (подложка/объект/леттеринг/фактура), **точный размер и пропорцию** места на холсте, **цвет фона по каждому краю** (hex), **где будет текст** (пустая зона, координаты в долях), **стиль-якорь** (одна фраза, одинаковая для всех компонентов истории), **запреты** (без текста, без рамок, без водяных знаков, без людей — если не нужно). Генерируй в максимальном разрешении инструмента с той же пропорцией; масштабируй в SVG через `preserveAspectRatio="xMidYMid slice"`.

Стиль-якорь (пример): «документальная риза: тёплый бетон, мягкий дневной свет, лёгкое зерно плёнки, приглушённые цвета, без глянца». Повторяй его дословно в каждом промпте — это и есть единый стиль.

## §1 Подложка (фон холста)

- Варианты: весь холст (только если генератор держит 5.6:1 — обычно нет), **сегменты по 3 карточки (3240×1350 = 2.4:1)** или **по 2 (2160×1350 = 1.6:1)**. Обложку и CTA часто удобно делать отдельными сегментами.
- Стык сегментов: в промпте каждого сегмента — «левый край — ровный цвет #XXXXXX на ширине 8 %, правый край — #YYYYYY на 8 %», где цвета совпадают с соседними сегментами. Стык сегментов ставить **не на шов карточек**, а внутри карточки (≥ 200 px от реза), и прикрывать мостом/объектом.
- Подложка без текста и без деталей там, где будет текст: «спокойная зона в левой трети / по центру».

Шаблон: `Фон для [N] вертикальных карточек, общая пропорция [W:H], [тема/среда]. [Стиль-якорь]. Спокойные однородные зоны для текста: [где]. Левый край переходит в ровный цвет [#hex], правый — в [#hex]. Без текста, без рамок, без людей, без логотипов.`

## §2 Объект на фоне зоны (герой, памятник, предмет)

Шаблон: `[Объект] — [ракурс, точная форма по фото-референсу, без выдумывания деталей]. Объект целиком, по центру, занимает 70 % высоты. Фон — ровный [#hex зоны] без теней и текстуры (или: фон точно повторяет [описание подложки]), мягкая тень снизу 15 %. [Стиль-якорь]. Без текста.`
Для документального объекта: давать реальное фото как референс, требовать «сохранить геометрию, количество элементов, пропорции». Если форма искажена — использовать исходное фото с маской/скруглением (никогда не публиковать искажённый документальный объект).

## §3 Фактура и фоновый мотив

`Фактура [бумага/бетон/ткань], равномерная, бесшовная, светлота [L*≈90], без объектов и текста, [стиль-якорь].` Мотив (орёл, герб, силуэт): `[мотив] графически, контур/гравюра, одноцветный [#hex] на [#hex], без текста` → накладывать с непрозрачностью 6–12 %.

## §4 Леттеринг

`Надпись «[ТОЧНАЯ СТРОКА]» [материал/стиль: рельеф по бетону / плакат 1970-х / неон / мел], буквы кириллицей точно как написано, [цвет букв #hex] на ровном фоне [#hex зоны], пропорция [W:H], надпись занимает 85 % ширины, ровная базовая линия, без других слов.` После: сверка букв; ошибка → повтор с «буква X неверна, нужна "Ж"».

## §5 Иконки как подсказка генератору

Найди иконку (`get(scope:icons)`), посмотри её; в промпт: «в стиле линии как у иконки: [толщина, скругления, заливка]» либо вставь иконку inline в SVG и генерируй фон вокруг пустого места под неё.

## Контроль качества сгенерированного

Перед импортом посмотри компонент: (1) края совпадают с цветом зоны (ΔE < 3 на 8 % края); (2) нет случайного текста/артефактов, лишних пальцев, «каши»; (3) стиль совпадает с якорем; (4) у документального объекта не изменена форма. Не прошёл — перегенерируй с конкретным уточнением (что именно не так), а не «сделай лучше». Максимум 3 попытки на компонент — затем упростить (фото + маска, или типографика).


## Базовые рецепты
### Генеративный леттеринг → страйпы


1. Сохранить точную строку, роль, будущий размер и фон размещения. Генерировать художественную надпись с нужным рисунком и материалом.
2. Посмотреть реальный файл и исправить буквы. Выделить всю надпись или bbox каждой строки; bbox не должен обрезать выносные элементы и тени.
3. Получить прозрачный слой разрешённым инструментом; не считать белый фон альфой. Если подготовка/правка делается генератором, проверить результат повторно. После подготовки файл остаётся редактируемым компонентом, а строка — текстовым источником.
4. Передать исходные PNG/RGBA через проверенный original/file путь, не через нормализованную белую производную. Точный byte handoff ещё предстоит испытать.
5. Положить полосы в общий холст, проверить край на настоящем фоне, текст в масштабе телефона и переходы. При смене копирайта заменяется соответствующий компонент, не весь фон.

### Подложка целиком или сегментами по 2–3 карточки


Сначала выбрать роль и крупность текстуры. Общий фон легче держит единство, но большое растяжение может лишить деталь резкости. Сегменты сохраняют разрешение, зато требуют согласования света, перспективы и кромок. В задание dot входят bbox/размер, вид соседнего фрагмента, палитра и зоны будущего текста. Перекрытие или продолжение существующего края — возможный способ, один seed сам по себе не гарантирует совпадения. После монтажа сравниваются обе стороны стыка; при необходимости правится край, маска или конкретный сегмент. Реальный генеративный прогон отложен до E2E.

### Тихий смысловой мотив


Бренд, контекстный предмет, слово или исторический символ можно встроить в фон либо положить отдельным слоем. Отдельный слой проще двигать и менять, встроенный — проще объединить с фактурой; выбор зависит от реального результата. Начинаем с роли «вторичный», затем настраиваем видимость на фактическом фоне. Opacity, насыщенность и контраст — разные величины; «8%» не универсальная гарантия читаемости. Мотив не должен выдавать художественную реконструкцию за документальную деталь фотографии. После платформенного сжатия проверяется фактическая видимость.
