# 10 · Сторителлинг: история за 4–9 карточек

## 1. Ядро истории (до раскадровки)

Сформулируй три строки, иначе не начинай:
- **Обещание обложки:** что человек получит, если пролистает («у памятника есть имя, которое забыли»).
- **Поворот:** неожиданный факт/контраст, ради которого история существует.
- **Вывод/действие:** что читатель понял или сделает (CTA).

Если поворота нет — это не карусель, а один пост. Найди поворот в источниках или сократи до 4 карточек.

## 2. Роли карточек (словарь для диалога)

| Код | Роль | Что делает | Типичная доля |
|---|---|---|---|
| HOOK | Зачин-обложка | Обещание/вопрос/интрига + главный визуал; без ответа | 1 |
| CTX | Контекст | Где/когда/кто; одна мысль | 0–1 |
| FACT | Факт | Одно утверждение + доказательство (фото, документ, источник) | 1–3 |
| QUOTE | Цитата | Подлинная реплика/надпись с атрибуцией | 0–1 |
| METRIC | Метрика | Одно число как визуальная доминанта + единица + база сравнения | 0–2 |
| TURN | Поворот | Контраст «было/стало», «думали/оказалось», загадка | 1 |
| DETAIL | Деталь | Крупный план, вырезка объекта, «присмотритесь» | 0–2 |
| GAP | Пробел знания | Честное «мы не знаем», вопрос к аудитории | 0–1 |
| MEANING | Смысл | Почему это важно сейчас | 1 |
| CTA | Действие | Что сделать: прийти, рассказать, сохранить, ответить | 1 (последняя) |
| PAUSE | Типографическая пауза | Только крупный текст, смена ритма | 0–1 |

Правило: **одна карточка = одна роль = одна мысль**. Две мысли — две карточки или выкинуть одну.

## 3. Арки (выбери одну и назови её в отчёте)

| Арка | Последовательность ролей (7 карточек) | Когда |
|---|---|---|
| Загадка → разгадка | HOOK(вопрос) → CTX → FACT → DETAIL → TURN(ответ) → MEANING → CTA | Объект с неочевидной историей |
| Было/стало | HOOK → CTX(тогда) → FACT → TURN(сейчас) → DETAIL → MEANING → CTA | Утраты, реставрации, изменения города |
| Миф/факт | HOOK(миф) → FACT → FACT → QUOTE/источник → TURN → MEANING → CTA | Распространённое заблуждение |
| Таймлайн | HOOK → 4×FACT(даты на нити) → MEANING → CTA | Последовательность событий |
| Голос | HOOK(цитата) → CTX → QUOTE → DETAIL → TURN → MEANING → CTA | Человек, автор, свидетель |
| Число | HOOK(METRIC) → CTX → METRIC(сравнение) → FACT → TURN → MEANING → CTA | Есть проверенные числа |
| Маршрут | HOOK → точки 1–4 (FACT+DETAIL) → MEANING → CTA(прийти) | Места, прогулка |
| Сравнение | HOOK → A → B → A vs B → TURN → MEANING → CTA | Два объекта/эпохи |

## 4. Зачины (HOOK): формулы, проверенные для лент

1. Имя вместо описания: «У этого памятника есть имя». 2. Вопрос без ответа: «Куда исчезли гербы?». 3. Противоречие: «Его видят тысячи — и никто не знает, что это». 4. Число: «1977 — и ни одной таблички». 5. Прямое обращение: «Вы проходите мимо каждый день». 6. «До/после» одним кадром. 7. Деталь крупно + «присмотритесь». 8. Цитата-надпись. 9. Список-обещание: «5 деталей, которые вы не замечали». 10. Неожиданный ракурс + короткое слово.
Требования: заголовок обложки ≤ 7 слов, читается за 1 секунду в превью ленты; главный визуал занимает ≥ 45 % обложки; на обложке нет ответа.

## 5. Заголовки карточек

- 2–7 слов, глагол или конкретное существительное; без «Интересный факт», «Немного истории».
- Тело карточки ≤ 35 слов (≤ 3 строки по 12 слов на 1080 px при кегле 36–40). Больше — в подпись поста.
- Каждый заголовок должен продолжать предыдущий: прочитай только заголовки подряд — это должна быть связная история.

## 6. Факты и честность

- Каждый факт — с источником (подпись мелким кеглем или подпись поста). Неподтверждённое — роль GAP и формулировка «по данным…», «мы не нашли документа…».
- Не генерировать документальные детали (надписи, гербы, таблички) как будто они есть на объекте. Генеративная обработка допустима для подложки, стиля, леттеринга, реконструкции **явно помеченной**.

## 7. CTA (последняя карточка)

Формулы: «Расскажите в комментариях…», «Сохраните маршрут», «Приходите на проспект Калинина, 1», «Отметьте того, кто…», «Если знаете, что было на табличке — напишите». CTA конкретный, одно действие, крупно, + бренд «Полюбить Калининград».

## 8. Подпись поста (caption)

3 абзаца: (1) обещание в одну строку; (2) 2–4 предложения истории с фактами; (3) источники ссылками + вопрос к аудитории. Без хэштег-стен (≤ 3 тематических).

## 9. Варианты (A/B/C)

Когда владелец просит варианты или тема допускает разные трактовки: варианты различаются **аркой и главным визуальным приёмом**, а не цветом. Пример: A — «Загадка» на вырезке объекта; B — «Число» с метрикой-доминантой; C — «Голос» с типографическими паузами.
