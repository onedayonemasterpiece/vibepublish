# 85 · Стилистическая выдержанность при генерации по частям

Риск: компоненты, сгенерированные по отдельности, получают разные манеры у одинаковых сущностей. **Стилистическое единство одной истории обязательно:** заголовки карточек сохраняют одну манеру; акценты, повествование, цитаты и другие разные роли уместно и заметно различаются в общем визуальном языке. Разнообразие не означает смену почерка у каждого заголовка. Следующая история может иметь собственный характер леттеринга.

## §1 Стилевой паспорт истории (обязателен до первой генерации)

Составь после шагов 4–5 процесса (палитра, типографика) и сохрани первым `revise.note`, а также в `brief` (раздел «Стиль»). Обновляй, если меняешь решение.

**Сначала выбери семейство стиля под историю и цель «продать историю» — не по умолчанию.** Примеры E01–E23 в основном чистые, чёткие, местами глянцевые. Состаренная бумага, дуотон и зерно — один из вариантов для особого замысла (архивное досье), а не стартовая точка: современные фото не состариваются автоматически ради единства оформления.

| Семейство | Подложка | Фото | Когда |
|---|---|---|---|
| Чистый современный | плоский цвет или мягкий градиент, много воздуха | естественный цвет, резкие, вырезки с тенью | подходит для города, места, людей сегодня |
| Глянцевый плакат | насыщенный цвет, блики, объём в леттеринге | контрастные, крупные вырезки | событие, призыв, сильная эмоция |
| Редакционный журнал | светлый фон, сетка, тонкие линии | естественный цвет + 1 акцент | расследование, объяснение, данные |
| Было/стало | современная часть — чистая, архивная — своя фактура | архив как есть (ч/б, с атрибуцией) рядом с цветным сегодня | есть исторический снимок |
| Архивное досье | бумага, скрепки, печати | документальная фактура; современные фото без автоматического старения | когда архивная подача поддерживает замысел |

Пример паспорта ниже — для одной истории, не шаблон стиля; его зерно, приглушённые цвета и числа не переносятся автоматически в другие работы.

| Поле | Пример |
|---|---|
| Стиль-якорь (1 фраза, дословно в каждый промпт) | «советский модернизм в документальной подаче: тёплый бетон, мягкий дневной свет, лёгкое плёночное зерно, приглушённые цвета» |
| Палитра (роли B/T/A/P/AT, hex) | B `#E9E6DF`, T `#1F1F1F`, A `#C8102E`, P `#F4F1EA`, AT `#FFFFFF` |
| Фактура и свет | бетонная крошка 5–8 %, свет слева сверху, тени мягкие 25 % |
| Геометрия | скругления r 32; линии 6 px; иконки — контур 2 px, скругл. концы |
| Роли текста → исполнение (манеры леттеринга — из каталога 40-typography, любые) | HOOK — генеративный рельеф по бетону; сильная фраза — генеративный плакатный конденсированный гротеск 70-х; CTA — генеративные объёмные буквы на акцентной ленте; QUOTE — генеративная рукопись пером; число — генеративная латунь таблички; заголовки карточек — генеративный леттеринг манеры паспорта; повествование — короткие читаемые сгенерированные мини-абзацы с согласованным характером и разной компоновкой |
| Роли медиа → исполнение | современные фото — естественный цвет, скругление; архивный снимок — как есть; необходимая датировка сохраняется, подробные источники и полные блоки атрибуции/лицензий — в подписи поста; компактная подпись автора/источника на карточке — по 10-storytelling §6; герой — вырезка с единой тенью; подложка — по замыслу, на весь холст или группы по 2, 3 или 4 карточки; спокойные однотонные участки допустимы и не отвлекают от героя |
| Сколько приёмов | пример для этой истории: 1 ведущий + 1–2 живых слоя (L-приёмы), 2 семейства шрифтов; манеры леттеринга определяются ролями и замыслом, не фиксированной квотой |

## §2 Перед каждой новой генерацией

1. **Посмотри уже сделанное той же роли:** `render(view:"region")` на места, где стоят предыдущие компоненты этой роли, либо `get(scope:"components")` — лист всех ассетов карусели с ролями (когда доступно). Для первой генерации роли — посмотри соседние карточки.
2. **Подай их генератору как образец стиля:** 1–2 изображения ранее сделанных компонентов той же роли + формулировка «в том же стиле, манере, фактуре и свете, что приложенный образец; новое содержание: …». Для подложек — фрагменты краёв соседних сегментов (60-generation §1, F1).
3. **Стиль-якорь дословно** + роль из паспорта («это заголовок карточки, манера как у предыдущих заголовков…» или «это CTA, манера CTA из паспорта»).
4. **Отличие задаётся ролью, не стилем:** CTA отличается от заголовка плашкой и шрифтом из паспорта, а не новой фактурой или новым светом.

## §3 Проверка выдержанности (добавь в ревью master)

| ID | Проверка | Признак брака | Исправление |
|---|---|---|---|
| ST1 | Один свет | тени в разные стороны, разная жёсткость | перегенерировать отличающийся компонент с образцом |
| ST2 | Одна фактура | бумага и глянец рядом без смысла | унифицировать (70-montage §6) или заменить |
| ST3 | Единая манера внутри одной роли | два разных «почерка» у одной роли | перегенерировать по образцу первого |
| ST4 | Роли различимы | CTA выглядит как заголовок, цитата как тело | усилить исполнение роли из паспорта |
| ST5 | Цвета только из паспорта | новый оттенок без роли | привести к роли палитры |
| ST6 | Иконки одной системы | разная толщина/заливка | один набор, одна толщина |
| ST7 | Разнообразие есть | все карточки одной схемы, «каталог» | сменить крупность, роль, приём (20-composition ритм) |

## §4 Разнообразие внутри единого стиля (как в примерах E01–E23)

Допустимо и желательно: разные роли текста и их исполнения; смена крупности; карточка-пауза на типографике; вырезка на одной карточке, панорама на другой; число-герой. Недопустимо: смена стиля-якоря, света, фактуры, манеры леттеринга внутри одной роли.
