# 95 · Инфографика: число как визуальная доминанта

## Когда
Есть проверенное число, которое меняет понимание (год, количество, доля, сравнение). Число без источника, единицы и базы — не используется.

## Анатомия числа-героя (METRIC)
- Число: Display 220–420 px (Unbounded 800 или Oswald 700), цвет акцента, занимает 45–70 % ширины карточки.
- Единица и период — рядом, H2 60–84 px: «лет», «шагов», «% жителей, 2024».
- Смысл одной строкой, Body: что это значит.
- Источник: Caption ≥ 24 px внизу.
- Число может пересекать шов (S15) — разрез между знаками.

## Сравнение
- Две величины одной природы, одна шкала: столбцы/круги пропорциональны **площади для кругов, длине для столбцов**. Никогда не 3D.
- Изменение: «было → стало» с одинаковой базой; процент и процентные пункты не путать.
- Отсутствующие данные — пустая рамка/«нет данных», не ноль.

## Типовые формы
| Форма | Когда | Как |
|---|---|---|
| Большое число | один факт | число + единица + смысл |
| Пара чисел | до/после | одна шкала, стрелка-жест S08 |
| Шкала времени | даты | нить S06 с узлами, расстояния ~ пропорционально времени или явно «не в масштабе» |
| Доля | часть целого | 10×10 точек или полоса 100 % |
| Счётчик предметов | количество | повтор иконки (≤ 20), остальное «+N» |

## Проверка
Q04, Q13, Q22 из 90-review + «прочитай число вслух с единицей и базой — понятно ли без подписи поста?».
