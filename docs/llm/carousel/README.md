# Story Carousel — руководство модели

**Работай по шагам.** Начни с `get(scope:"guide", topic:"steps/s01")`; каждая карточка шага короткая, говорит, что сделать и какие фрагменты библиотеки взять (`topic` + `section`), и даёт следующий шаг. Не загружай библиотеку целиком.

Инструкции для модели, которая делает бесшовные карусели-истории через `vibepublish_carousel`. Отдаётся в рантайме: `get(scope:"guide")` — оглавление тем; `get(scope:"guide", topic:"<глава без .md>")` — заголовки разделов и их объём; добавь `section:"<заголовок или его начальный префикс>"`, чтобы получить один раздел целиком и только связанные с ним изображения MCP. Карточки `steps/s01`–`steps/s10` возвращаются целиком без `section`.

Шаги: s01 смысл → s02 раскадровка → s03 скетч → s04 палитра и типографика → s05 стилевой паспорт → s06 подложка → s07 компоненты → s08 монтаж → s09 ревью → s10 экспорт и публикация.
