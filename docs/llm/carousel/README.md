# Story Carousel — руководство модели

Инструкции для модели, которая делает бесшовные карусели-истории через `vibepublish_carousel`. Отдаётся в рантайме: `get(scope:"guide")` — оглавление, `get(scope:"guide", topic:"<файл без .md>")` — раздел целиком с картинками.

| Раздел | О чём |
|---|---|
| [00-process](00-process.md) | Порядок работы от поручения до отложенного поста, размеры, безопасные зоны |
| [10-storytelling](10-storytelling.md) | Ядро истории, роли карточек, 8 арок, зачины, заголовки, CTA, подпись, варианты |
| [20-composition](20-composition.md) | Сетка и числа холста, паттерны C01–C16, оси вариативности, приёмы из примеров E01–E23 |
| [30-seams](30-seams.md) | 24 моста S01–S24 с геометрией, проверка швов |
| [40-typography](40-typography.md) | Шрифты пакета и пары, шкала кеглей, сильная типографика, генеративный леттеринг |
| [50-palettes](50-palettes.md) | Процедура палитры, 12 палитр с контрастом, тематические опоры |
| [60-generation](60-generation.md) | Шаблоны промптов: подложка сегментами, объект на фоне зоны, фактура, леттеринг; контроль качества |
| [70-montage](70-montage.md) | SVG-рецепты: скругления, маски, вырезки, страйпы, скрим, цвет, фоновое слово, нить, панели, иконки |
| [80-variation](80-variation.md) | Оси вариантов, A/B/C, анти-повтор |
| [85-style-continuity](85-style-continuity.md) | Стилевой паспорт истории, преемственность компонентов, образцы для генератора, проверки ST1–ST7 |
| [90-review](90-review.md) | Три прохода ревью, банк Q01–Q35, V01–V30, R01–R15, инженерные проверки K01–K13 |
| [95-infographics](95-infographics.md) | Число-герой, сравнения, формы |
| [99-platform](99-platform.md) | VK/Telegram, выпуск |

Реальные примеры-картинки: `get(scope:"library")` → `get(scope:"reference", reference_id)`; в разделах указаны подходящие ID.
